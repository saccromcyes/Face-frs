How it works
  1. Detect faces with a Tiny Face Detector (a 190 KB network).
  2. Locate 68 landmarks per face: eyes, brows, nose, mouth, jaw.
  3. Embed each aligned face as a 128-number descriptor with a ResNet-34-style recognition network.
  4. Match by Euclidean distance to the stored face prints; the threshold trades false matches against missed ones.
  5. Liveness: the eye aspect ratio (eye height ÷ width from the landmarks) drops sharply during a blink; two dips within ten seconds pass.

All models run with TensorFlow.js on your GPU (WebGL) or CPU. Face prints are kept in this browser's storage so they survive a reload, until you forget them. The only network requests are the one-time model downloads.
